# Frontend — PyQuest Web (React)

Wajah aplikasi: peta petualangan & game (mahasiswa) + dashboard kelola soal (dosen).

> Masih kosong — akan dibuat mulai **Fase 3** (`npm create vite@latest`).

## Rencana isi
```
frontend/
├── src/
│   ├── pages/         # Login, Peta, Level, Dashboard Dosen, ...
│   ├── components/    # tombol, kartu, HP bar, node peta, ...
│   ├── api/           # panggil backend
│   └── App.jsx
├── index.html
└── package.json
```
